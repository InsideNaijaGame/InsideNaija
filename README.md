# InsideNaija v3.0.0

Nigerian life simulation / multiplayer browser game.

## Deploy (Render)

- Build: `npm install`
- Start: `npm start`
- Health: `/api/health`

## Features (v3)

- Three.js third-person 3D world (Lagos-style)
- Visible humanoid character (body, head, arms, legs) with idle + walk/run animation
- Name tag above player
- Virtual joystick + RUN + Interact (mobile)
- Keyboard WASD + Shift + E (desktop)
- Smooth third-person camera follow
- Real Socket.IO multiplayer (other players' humanoids visible)
- Global chat
- Phone UI: Messages, Jobs, Bank, Map, Profile, Inventory, Transport, Settings
- 12 Nigerian jobs with pay, XP, energy, skills
- Wallet + bank (₦)
- All 36 states + FCT travel map
- Interactive locations (shops, food, jobs, bank, homes)
- Local progress persistence
- PWA manifest + service worker
- Loading screen with progress

## Run locally

```bash
npm install
npm start
# open http://localhost:3000
```
